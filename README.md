# Артём Назаров

Python / Django backend-разработчик. В заказной разработке занимался CRM-аналитикой, внутренними панелями управления и системами учёта посещаемости. Также создавал сайты на заказ, скрипты и парсеры.

Объединял данные YClients, amoCRM, Mango Office и 1C, строил отчёты для руководителей и менеджеров. В серверной части работал с API, авторизацией, обработкой данных, кэшированием и автоматическим обновлением. Большая часть коммерческого кода закрыта по NDA; задачи и технические решения могу обсудить на собеседовании.

Основной стек: Python, Django, FastAPI, PostgreSQL, Redis. Также работаю с JavaScript и TypeScript, Docker и Linux.
